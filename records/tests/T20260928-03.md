# T20260928-03 — 실험 실행기 mock (세션 A, A3)

- **목적**: 컨트롤러 검사를 켠 실행기로 직선·제자리 회전·사각을 돌려 bag·추출·오도메트리 비교가 맞는지, 실행 중 실행기 SIGINT와 CLI Ctrl-C의 정리 경로가 맞는지.
- **조건**: T-02의 mock 런치 위에서 `runner -p require_preflight:=false -p require_power:=false`(require_controller 켬), `oroha_exp run … --rig-state mock --yes`.
- **관측**:
  - ARM의 컨트롤러 활성 검사(`list_controllers` 서비스 호출) 첫 실사용 통과.
  - 직선 1 m: odom 1.000 m = 이상값. 사각 1 m: 폐합 0.0001 m, yaw 6.2833(이상 6.2832) — H10(시작 자세 기준·yaw 연속) 확인.
  - **결함 발견·수정**: 첫 spot 360°에서 odom yaw 5.35 rad(−0.93). 원인 둘: ① bag 녹화기가 실행기 토픽(cmd_vel·이벤트·상태)을 START 후 3.15 s에야 구독(DDS 탐색 지연, 비결정적) → 첫 3 s 명령 누락, ② 이벤트 토픽이 transient_local이라 새 녹화기가 이전 실행의 이벤트를 받고, 추출기가 bag 수신 시각 기준 첫 START(이전 실행)를 t=0으로 씀. 수정: 실행기는 녹화기가 발행 중인 모든 기록 토픽을 구독한 뒤에만 BAG_STARTED/ARM 완료, 추출기는 **이 실행 run_id의 START 이벤트 header stamp**를 t=0으로 쓰고 다른 실행 이벤트 제외(`foreign_events_skipped`). 재추출: yaw 6.2832, 재실행 spot: 첫 명령이 START 이전부터 기록, yaw 6.2832.
  - 실행 중 실행기 SIGINT(t≈4 s): ABORT("runner stopped") → BAG_STOPPED rc=0 → meta `ABORTED`, `metadata.yaml` 있음, 고아 녹화기 0, CLI는 상태 3 s 끊김으로 "RUNNER LOST" 종료(추가한 감지).
  - 실행 중 CLI Ctrl-C: "Ctrl-C -> ABORT" → 실행 `ABORTED`(abort requested), 실행기는 IDLE 유지.
  - 원장: mock 실행 7건 모두 `usable=no`(규칙 DONE ∧ on_ground).
- **판정**: 통과(수정 후) / 종결. 실행 자료: `data/runs/R20260928-1631*`~`R20260928-163702-*`.
