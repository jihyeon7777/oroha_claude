# T20261006-08 — E-stop 접점 정지 확인 (DI 20 Hz, 모터 명령 없음)

- **조건**: 런치 없음, 로봇 바닥·토크 오프. `oroha_di_watch --sec 60 --rate 20`(두 MD400 DI·status 번갈아, 각 50 ms) 동안 사용자가 E-stop을 ① 아주 천천히 끝까지 눌렀다 해제 ② 빠르게 눌렀다 해제. 기록 `T20261006-08/di_watch_estop.csv.gz`.

| 동작 | 오른쪽(id1) | 왼쪽(id2) |
|---|---|---|
| 천천히 누름 | 18.344 s 0x34→0x60 (DIR·START_STOP 동시에 떨어짐) | 18.377 s 0x34→0x20 |
| 해제 | 20.841 s | 20.874 s |
| 빠르게 누름 | 21.628 s | 21.661 s |

- 두 접점은 측정 분해능(33 ms 간격 교대 읽기) 안에서 함께 열리고 닫혔다. 각 MD400에서 DIR(b2)·START_STOP(b4)도 늘 함께 움직였고, 한쪽만·반쯤 열린 상태는 없었다. status는 내내 0.
