# T20260928-05 — 방향 점검: 슬레이브 id ↔ 바퀴 ↔ +rpm 방향 (세션 A, A5)

- **목적**: `oroha_controllers.yaml`의 `motor_id_L 2 / motor_id_R 1`, `reverse_L true / reverse_R false`를 실물과 대조(확인표 §5).
- **조건**: 바퀴 띄움, E-stop 사용자 손, 모터 버스 ON(id1 27.70 V·id2 28.40 V, T-04). 직접 Modbus(`oroha_direction_check`, 실행 전 `USE_LIMIT_SW` 1→0 = 플러그인과 같은 운용값, `ENC_PPR 1000`, `USE_EPOSI 0`). 한 대씩, 끝나면 항상 0·stop·torque_off.
- **절차·관측** (`records/tests/T20260928-05/direction_*.json`):
  1. 100 rpm × 3 s (id 1, id 2): 정속 100.3 / 99.8 rpm, 위치 +142 / +142 counts, 첫 회전 0.148 s, 알람 없음. **사용자: 바퀴 속도(약 2.9 바퀴rpm)가 낮아 육안 판별 불가** → 도구 rpm 상한 300→600(띄운 점검용).
  2. 500 rpm × 5 s (09:11:29Z, 09:11:42Z): 정속 499.9 rpm(sd 4.6) / 500.5 rpm(sd 5.8), 위치 +1212 / +1215 counts(이론 1250에서 가속분 차), MD400 내장 전류 0.18 / 0.00 A(0.1 A 분해능), 알람 없음 — 엔코더 속도 루프(`ENC_PPR 1000`)에서 ENC_FAIL 없음.
  3. **사용자 관측: id 1 → 오른쪽 바퀴 전진, id 2 → 왼쪽 바퀴 후진.**
- **판정**: 통과 / 종결. id1=오른쪽(+rpm 전진), id2=왼쪽(+rpm 후진, 거울 장착)으로 확인표·설정과 일치. 위치 카운트는 +rpm에서 증가(두 대 모두), 30 counts/모터회전과 정합.
- **버전**: ws `216594f`+direction_check rpm 상한 변경(이 시험 커밋에 포함), external c5c1f3f.
