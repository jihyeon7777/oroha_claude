# T20260922-04 — Pico 펌웨어 1.2 플래시 (2단계 선행, 모터 무동작)

- **목적**: 실물 Pico로 `oroha_power`를 돌리다 발견한 결함 수정. 펌웨어 `mono_us()`가 D 라인 출력 때만 `ticks_diff`를 누적해, 스트림이 537 s(2^29 µs) 넘게 멈춘 뒤 재개하면 `t_us`가 감겨 음수/역행 → 호스트 노드가 uint64 변환에서 죽음(`OverflowError: can't convert negative int to unsigned`, preflight의 `X` 후 약 10분 유휴 뒤 재현).
- **수정**: (1) 펌웨어 유휴 루프에서도 `mono_us()` 호출, `FW_VERSION = oroha-bench-1.2` (표본·프로토콜·상수 변경 없음). (2) `PowerSample.t_us`를 int64로, min/max를 int16으로 바꿔 원값을 보존하고, 노드는 프레임 하나가 잘못돼도 죽지 않게(`n_bad` 집계) 하며 `t_us` 역행은 `device_restarts`로 셈.
- **절차**: `mpremote fs cp firmware/pico/main.py :main.py` → 장치 `main.py` sha256 = `bace9505…`(저장소 파일과 동일) → `reset` → `C`: `#CFG fw=oroha-bench-1.2`, `#STAT zero_valid=1`. 1.1 원본은 `firmware/pico/archive/main-1.1.py`(sha `9ce752a9…`)로 보관.
- **판정**: 통과(플래시·식별) / **열림**: 537 s 유휴 후 재개 시 `t_us` 연속성은 아직 미검증 → 별도 시험(스트림 X → 10분 대기 → S → t_us 단조 확인).
- **버전**: ws `7bcf2c5` + 미커밋(펌웨어 1.2, msg 변경), fw sha `bace9505…`.
