# T20261006-11 — 띄운 상태 제동 시험: USE_LIMIT_SW 1 ↔ 0

- **조건**: 바퀴 띄움, 런치 없음. `oroha_brake_test --modes 1 0 --high 1500 --low 300 --hold 2`. 두 MD400을 1500 rpm에서 300 rpm(0이 아닌 같은 방향)으로 계단 감속 → 0. 모터 폴링 20 Hz, Pico 계측 bag `data/tests/T20261006-11/bag`. 0 모드 몇 초 동안 E-stop은 무효였고, 끝난 뒤 양쪽 USE_LIMIT_SW=1로 복원하고 읽어서 확인.

| | USE_LIMIT_SW 1 | USE_LIMIT_SW 0 |
|---|---|---|
| 1500 → 300 rpm ±10 % 도달 | id1 0.46 s · id2 0.40 s | id1 0.46 s · id2 0.39 s |
| id1 속도(계단 뒤 0.1 s 간격) | 1132, 628, 513, 435, 386, 361, 341, 326, 315 | 1140, 596, 506, 435, 386, 358, 339, 330, 316 |
| 고속 구간 Pico 전류 L/R | +0.64 / +0.79 A | +0.63 / +0.78 A |
| 계단 뒤 0.8 s 평균 / 최저 평균 | +0.25 / +0.02 A | +0.25 / +0.01 A |
| 20 ms 창 최소 | −0.08 / −0.06 A | −0.09 / −0.09 A (잡음 수준) |

- 두 모드가 같다. 계단 뒤 전류는 0으로 떨어질 뿐 제동(음) 전류가 없고, 감속은 기어·벨트 마찰(처음 0.1 s에 1500 → 600 rpm, 이후 완만)뿐이다.
- **판정**: 통과(측정) / 종결 — **가설 기각**: `USE_LIMIT_SW`는 제동과 무관하다. **MD400(fw 8.6, 현 설정)은 0이 아닌 속도 명령에서 바퀴가 과속해도 제동 토크를 내지 않는다**(0 명령에서만 정지 브레이크). 접지에서 생기는 결과:
  - 스키드 곡선의 안쪽 바퀴를 붙잡지 못해 원·S 곡선을 수행하지 못함(T20261006-10)
  - 관성이 바퀴를 미는 동안 출력 0, 그 뒤 와인드업과 OVER_LOAD(T20261006-07/09)
