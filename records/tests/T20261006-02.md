# T20261006-02 — 대기전류 직접 확인 (모터 전원 OFF ↔ ON 정지 raw)

- **조건**: 같은 Pi·Pico·배선, 바퀴 띄움, 모터 정지. 06:25Z 모터 전원 OFF 상태 preflight(`records/preflight/20261006T062539Z.json`, NO-GO: MD400 무응답, GP26 raw 0.0) → 사용자가 전원 ON → 06:35Z preflight(`20261006T063539Z.json`, GO 28/28, 15 s). 전원 OFF의 정지 raw는 대기전류가 없는 **참 0 A** 직접 측정값.

| | GP27 (왼쪽 id2) | GP28 (오른쪽 id1) |
|---|---|---|
| 전원 OFF (참 0 A) | 2030.655 (sd 1.70) | 2028.694 (sd 1.77) |
| 전원 ON 정지 | 2037.149 (sd 1.60) | 2035.292 (sd 1.61) |
| 차이 = 대기전류 | **+6.49 LSB = 74.3 mA** | **+6.60 LSB = 75.5 mA** |

- 교정 가정 7.0 LSB(80 mA, 08-28 DMM)와 −0.4~−0.5 LSB(−5 mA) 차이. 두 측정은 10분 간격이고 영점의 하루 변동은 ±2 LSB라 그 안이다. 전원 ON이 측정 접지를 크게 옮기지 않는다(옮겼다면 차이가 7 LSB에서 크게 벗어남).
- 참 0 A raw 자체는 교정일(2035.257 / 2033.974)보다 −4.6 / −5.3 LSB 낮다. 레일 또는 접지 이동으로, 실행별 정지 기준(D-14)이 처리하는 범위다.
- **판정**: 통과 / 종결. `i_*_abs = di + 0.080 A` 가정은 ±5 mA 수준으로 유효. 같은 순간의 OFF→ON 계단(연속 기록)은 선택 사항으로 남긴다.
